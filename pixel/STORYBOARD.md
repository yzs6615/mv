# 世界上唯一的花 · 像素风 MV 分镜

> 歌曲：《世界上唯一的花》中文翻唱版（原曲词曲：槇原敬之；中文词：林明阳），4:37，99 BPM，降 B 大调。
> 全片 480×270 原生像素，4 倍最近邻放大到 1080p60。画面全部由代码绘制：Canvas 2D 负责像素画，three.js 负责体素 3D 镜头，伪 3D（Mode-7）赛道是逐行采样算出来的。
> 时间均为歌曲时间（秒），L 编号对应逐句歌词。

## 视觉规则

| 项 | 规则 |
|---|---|
| 色板 | 只用 ENDESGA-32 的 32 种颜色。3D 渲染结果也会被量化回这 32 色，并做 Bayer 有序抖动 |
| 灰色世界 | 先按真实色彩画，再用后期把画面映射到蓝灰色阶。「色彩区」内保留原色，边缘做抖动过渡。霓虹、玫瑰、奇怪的种子使用「豁免色」（与原色只差 1/255 的蓝色），所以在灰色世界里也一直是彩色的 |
| 主角 | 戴草帽、系红围巾、穿绿色背带裤的小园丁。头和身体是手绘像素精灵，四肢按姿势参数实时画出，围巾尾巴会随风飘。灰色世界里他也是灰的，被色彩区覆盖后才恢复颜色 |
| 路人 | 一模一样的灰色市民：同样的发型、西装、表情。获得自由后，每个人由种子数生成专属的配色、发型和饰品 |
| 花 | 每朵花都由各自的种子数决定花型（8 种）、配色、茎高、叶子和倾斜，没有两朵相同。主角的花是歪的：一片普通叶子，一片彩虹故障叶，七片大小、颜色各不相同的花瓣 |
| 字幕 | Fusion Pixel 12px 像素中文字体。每个字在唱出的那一刻打出来并轻轻跳一下，正在唱的字是黄色的 |
| 音效 | 方波、三角波、噪声通道合成的 8-bit 音效，旋律类音效都在降 B 大调上，混在歌曲下面 |
