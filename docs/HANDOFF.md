## 2. 运行方式

```bash
python3 tui/lovestory.py --audio <你的 Love_Story.flac>   # 需要 ffplay 或 mpv 才有声音
python3 tui/lovestory.py --mute                           # 只看画面
python3 tui/lovestory.py --start 185 --audio ...          # 从转折处开始看
LS_CJK_FONT=/path/to/NotoSansCJKsc-Regular.otf \
python3 tui/lovestory.py --export out.mp4 --audio ...     # 离线导出（需要 Pillow 和 ffmpeg）
```

如果声音和画面对不上，用 `--sync 0.08` 调整画面延迟。按 `q` 退出。详细说明在 `tui/README.md`。

## 3. 这一版改了什么

- **中文叙事层 `tui/story.py`（新文件）**
  - 56 条原创中文旁白按小节排程，固定显示在底部两行（中文 + 英文小字），逐字打出。
  - 顶部 HUD：当前段落名（前奏 / 主歌 / 预副歌 / 副歌 / 桥段 / 最静处 / 转调副歌 / 终章 / 尾声）、按段落比例的歌曲
    结构进度条（当前段落随拍闪烁，`┃` 标出转调位置）、小节数、四拍指示 `●○○○`、BPM、调性（第 94 小节翻成 `E大调 ↑`）。
  - 每个段落有能量值（`ENERGY`），`energy()` 把它和实测响度混合；`kick()` 给第 1、3 拍一个衰减的重音。
  - 中文大字：`big_zh()` 用预渲染点阵和半格字符 `▀▄█` 画 16px（8 行）或 12px（6 行）的大字；`title_card()` 在章节
    第一拍上揭示标题，停 1–1.6 小节后向上淡出。
- **`tui/scenes.py` 全部重写为中文优先、按拍驱动**
  - 所有屏幕文字改为中文（启动日志、控制台、错误、日志面板、状态栏）；英文只保留 `ping` / `SYN` / `EACCES` 这类
    系统标识，并配中文说明。
  - 信息密度：每章都多了一个随拍滚动的日志面板（探测日志、每拍数据包账本、闸门记录、扫描记录、路由表）和
    一两行状态数据（距离、心率、已发信件数、已搜索格数、链路完整度、已接入节点数）。
  - 跟拍：副歌每两小节切一次图形（玫瑰线 k 值 / 瓣数），每个底鼓从中心打出一圈光环（`burst()`），星空流速、光晕
    呼吸速度、城市灯光亮度都由段落能量和底鼓驱动；预副歌里迷宫搜索用缓入缓出加速；桥段"最静处"留白。
  - 转调：第 93–94 小节右侧出现"升调准备"阶梯；第 94 小节全屏提亮、顶部出现 `♪ 转调 D 大调 → E 大调 · 升一个全音`，
    之后所有前景色整体向暖白偏移 12%。
  - 画布底部为旁白预留两行（`Ctx.H = cv.h - 3`），HUD 占第 0 行。
- **`tui/lovestory.py` 导出器**：支持 `▀▄` 半格字符；中文字体依次查找 `LS_CJK_FONT`、`build/cjk.otf`、常见系统路径，
  找不到会在 stderr 警告。
- **`tui/make_glyphs.py`（新）**：构建期工具，用 Pillow + 中文字体生成 `data/glyphs.json`（78 个字，两档尺寸）。
  运行时仍然只依赖标准库。要加新的大字，把字加进 `CHARS` 重新生成即可。
- **`tui/README.md`** 改为中文说明。

## 5. 已验证与未验证

**已验证**
- 全片每 0.25 秒一帧、五种终端尺寸（160×45、220×60、100×30、80×24、60×18）全部渲染无异常。
- 绘制一帧平均 2.5 ms（160×45）/ 3.1 ms（220×60），最慢 13 ms，30 fps 有余。
- 各章截图逐一检查（160×45 为主，220×60 和 100×30 抽查），修掉了标题与启动日志重叠、标题卡淡出残留黑块、
  握手文字与标题卡冲突、"第一支舞"缺字等问题。
- 在伪终端里实际跑过实时播放器（静音、真彩色和 256 色各一次）：30 fps，按 `q` 在 10 ms 内干净退出并恢复主屏幕和光标。
- 带歌曲音轨的完整离线导出成功（见第 1 节的预览视频）。

**未验证**
- 没有在真实的真彩色终端里带声音实际播放过（容器里没有声卡）。
- 实时播放器只支持 macOS / Linux / WSL（`termios` + `select`），原生 Windows 会报错。
- 终端字体必须有中文字形；如果终端把"宽度不确定"的符号（`● ◆ ♥ ✕ ⇄ ∞ ▮▯`）按两格显示，这些符号可能错位。
- 导出器写死了 DejaVu Sans Mono 的几个常见路径；中文字体需要 `LS_CJK_FONT`（本次用的是 Noto Sans CJK SC，
  没有提交到仓库）。
