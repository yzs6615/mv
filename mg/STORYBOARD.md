# 世界上唯一的花 · MG 动画 MV — 分镜与风格设定

> 歌曲：《世界上唯一的花》中文翻唱版（原曲词曲：槇原敬之；中文词：林明阳），4:37，99 BPM。
> 画面全部由代码绘制（Canvas 2D），每一帧都是时间的纯函数，卡点精确到帧。

## 1. 一句话

一颗不起眼的小种子「豆豆」，害怕自己永远比别人慢一步。它被风带着走过小镇、花店和整个世界，最后头顶开出了**世界上唯一的一朵花**，又把新的种子交给了下一个人。

## 2. 核心设定：每一朵花都是唯一的

片中出现的所有花（共 3142 朵）都由一个**种子数**通过代码生成：花型（10 种）、配色（14 套）、花瓣数、瓣形、层数、花心纹样、倾角、茎叶都由这个数决定。**片中没有两朵完全相同的花。** 这句话就是歌名本身。花店一场的标签卡、副歌二的图鉴墙上都标着每朵花的种子号，片尾字幕会写出总数。

## 3. 视觉风格：「孔版纸艺花园」

| 项 | 规则 |
|---|---|
| 质感 | 米色纸张、纤维和颗粒；扁平色块加墨蓝色描边；色块与描边错开 1–2 px，模仿孔版印刷的套色偏移 |
| 层次 | 主要物件带硬边投影，像纸雕叠层；远景降低饱和度 |
| 色板 | 纸 #F4EDE1 · 墨 #2A2E45 · 叶绿 #3E9B6E · 珊瑚 #FF6B5B · 金盏 #FFB627 · 粉 #F48FB1 · 薰衣草 #A78BDA · 天蓝 #6EC1E4 |
| 主角 | 豆豆：焦糖色小种子，豆豆眼、腮红、小短腿。开花后头顶长出茎，开出珊瑚色双层花，金色花心里有一颗星 |
| 字体 | 歌词用霞鹜文楷，英文与片名辅助用 Fraunces |
| 歌词动效 | 每个字在被唱出的那一刻落位，唱到时轻轻一跳；关键词换色；版式随镜头变：居中、竖排、三联分格、两级巨字 |
| 运动 | 一律用缓动曲线；推拉都在对数空间里插值；花和草在节拍上呼吸 |

## 4. 连贯性设计（一镜到底）

- **没有硬切**。衔接只有四种：
  - 穿越：推进橱窗、相片、图鉴格子，里面就是下一场。
  - 形变：色卡扇合拢变成相片，心形长成花海。
  - 跟随：镜头跟着花瓣、豆豆、绿线走。
  - 同构：导歌二重复导歌一的构图。
- **一条绿线**贯穿全片：土壤线 → 豆豆自己的路 → 图鉴上放射的小路 → 树枝 → 回家的路。
- **首尾呼应**：开场一颗种子落在土壤线上；结尾豆豆的花结出新种子，落在同样的土壤线上，上方用虚线画出一朵还没人见过的花。

## 5. 分镜表

时间为歌曲时间（秒），L 编号对应逐句歌词。

### 序 · 种下（0–12.6）
- **0–2.9**：一笔墨线画出土壤线，豆豆从天而降，在第 1 小节强拍落地。
- **2.9–7.7**（L0）：豆豆被种下，从土里探出头；唱到「唯一的花」时，上方用虚线画出它未来的花。
- **7.7–12.6**（L1）：镜头拉远，一整排种子，每颗上方的虚线花都不一样；「Only one」时豆豆的虚线变成珊瑚色。

### 片名 · 风起（12.6–32）
- **12.6**：乐队进入，所有虚线花依次绽放（梦里的未来）。
- **15.0**：片名逐字落下。
- **17.4**：一阵风把梦吹散成花瓣，豆豆踩着一片花瓣飞走。
- **19.8–32**：飞过纸雕小镇，房子随鼓点像立体书一样立起，最后落在街角花店的窗台上。

### 主歌一 · 花店（32–51.4）
- **L2**：花店门口一桶桶花，唱到「花的笑脸」时一朵接一朵露出笑脸。
- **L3**：穿过 16:9 的橱窗进入店内，三朵花按「微笑 / 鲜艳 / 亮丽」依次笑、恢复色彩、闪光。
- **L4**：镜头摇到花架，每朵花冒出不同的念头泡泡，豆豆的泡泡是问号。
- **L5**：沿花架横移，图鉴标签卡依次画出：种子号、瓣数、花型、色号。

### 主歌一后半 · 世界（51.4–70.8）
- **L6**：从橱窗一路拉远：花店 → 小镇 → 一颗点阵小星球，花从小镇出发，一圈圈开满地表。
- **L7**：星球右移并加速转动，花随八分音符爆开；圆形小窗里是豆豆惊讶的脸。
- **L8**：推进星球上的一朵花，变成大特写山茶，歌词竖排。
- **L9**：花瓣一片片飞下来，变成色卡，组成一把展开的色卡扇。

### 导歌一 · 害怕慢一步（70.8–90.1）
- **L10**：色卡扇合拢，变形成一张拍立得「小时候」：育苗盘里的小芽们咿咿呀呀，只有豆豆没发芽。
- **L11**：推进相片，回忆的颜色慢慢变鲜明；日历按八分音符翻页，时钟飞转，大家都很着急。
- **L12**：长高比赛：芽们沿刻度尺冲向天上的终点彩带，镜头一路跟着往上。
- **L13**：镜头落回最底下，只有豆豆还没发芽；一束暖光照下来，一滴水落在它头上。

### 副歌一 · 开花（90.1–112）
- **L14**：墙面像舞台布景一样升起，豆豆踩着四拍跳出育苗盘，每一步溅起清脆的圆环，脚下画出一条属于它的绿线。
- **L15**：头顶的芽抽高、结苞、在「最特别的花」时绽放；左侧是两级巨字。
- **L16**：周围的种子按八分音符一波波破土。
- **L17**：整片田野长高，镜头随之升起，在「开花」时从中间向两边绽放。
- **L18**：汗水和雨滴落下，每一滴溅开一大团颜色，把整个天空染满。

### 间奏 · 天变（112–132.6）
- **112–121.7**：花园随节拍跳舞，蝴蝶飞过。
- **121.7–131.4**：乌云从两侧合拢，天色变暗，起风。
- **131.4–132.6**：半小节的停顿里一切静止，一滴雨落向豆豆的花。

### 主歌二 · 风雨（132.6–171.4）
- **L19**：三联画：晴天的笑、小雨里的无助、乌云下的低落；第三格扩成全屏。
- **L20**：暴雨、闪电，豆豆被吹弯；唱到「不可以摇摆」时它站稳，周身亮起一圈金光。
- **L21**：云层裂开，一束光照下来，合拢的花重新打开。
- **L22**：入夜，豆豆种下一颗发光的梦想种子，光柱升起，照亮地平线。
- **L23**：带着笑脸的太阳升起，大家笑开怀。
- **L24**：一颗心把豆豆的花圈起来，里面开满小花，然后一下子炸开，镜头拉远成一望无际的花海。
- **L25**：豆豆和一只萤火虫一起穿过花海。
- **L26**：向阳的山坡，向日葵按拍子依次转向太阳，豆豆撒下的种子落地开出小花。

### 导歌二 · 传下去（171.4–190.8）
- **L27**：那张旧拍立得被风吹来，推进去：还是那个育苗盘，但盘里换成了新的一代，长大的豆豆站在旁边。
- **L28**：日历、时钟、着急的小芽们，和导歌一的构图一样，色调更亮。
- **L29**：新一轮长高比赛，豆豆不慌不忙地看着。
- **L30**：最小的那颗种子还没发芽，豆豆把花弯下来像伞一样遮着它，一滴水从花瓣上落下，它发芽了。

### 副歌二 · 每个人都开花（190.8–212.6）
- **L31**：整个房间缩成图鉴纸上的一个格子；十六条绿色小路按八分音符从这里放射出去，每条路上都有一颗种子，路的尽头开出一朵花。
- **L32**：中央格子换成豆豆的花，唱到「最特别的花」时亮起金框；每朵花下面标着种子号。
- **L33**：纸面扩展到 943 个格子，种子一波波发芽。
- **L34**：所有格子一起开花，拼成一朵由花组成的巨大的花。
- **L35**：彩色的雨，一道彩虹。

### 尾声 · Only one（212.6–232）
- **L36**：图鉴纸像一张纸一样被揭走，下面长出一棵树，每根枝头开一朵不同的花，歌词竖排。
- **L37**：枝头挂下三个圆相框：你（刚发芽的小种子）、我（豆豆）、他（开蓝花的兄弟）。
- **L38**：天空一半晴一半雨，然后每个相框里有了自己的天空：太阳、星空、彩虹。
- **L39**：镜头拉远，「我们全都是唯一」，最后盖章落下「Only one」。

### 片尾 · 啦啦啦（232–277）
- **232–236.8**：豆豆从「我」的相框里跳下来，落到树下。
- **236.8–268.3**：傍晚，豆豆沿着绿线走回家，每唱一声「啦」，脚边就开出一朵新花（共 65 朵）；演职员字幕随乐句依次出现，包括片中花朵的总数。
- **268.3–274.4**：景色褪回纸面，回到开场的土壤线。豆豆的花结出一颗新种子，种子在最后一个强拍上落地，上方用虚线画出一朵还没人见过的花。
- **274.4–277**：最后一下重音时花朵四周闪光，片名浮现，画面淡回纸色。
